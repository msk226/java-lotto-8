# 로또 

## 1. 구현 요구사항 체크리스트

### 1. 입력
- [ ] `구입금액을 입력해 주세요.` 문구 출력 후 금액 입력받기
- [ ] 금액을 기반으로 구매 개수 계산 (`금액 / 1000`)
- [ ] `X개를 구매했습니다.` 문구 출력
- [ ] 생성된 각 로또의 번호를 `[1, 2, 3, 4, 5, 6]` 형태로 출력
- [ ] `당첨 번호를 입력해 주세요.` 문구 출력 후 쉼표로 구분된 번호 입력
- [ ] `보너스 번호를 입력해 주세요.` 문구 출력 후 입력받기

---

### 2. 입력 검증
- [ ] 금액이 비어있거나 숫자가 아닐 경우 예외 발생
- [ ] 금액이 1000원 단위가 아닐 경우 예외 발생
- [ ] 금액이 1000원 미만일 경우 예외 발생
- [ ] 당첨 번호 입력이 비어있거나 숫자 이외가 섞여 있으면 예외 발생
- [ ] 당첨 번호가 6개가 아니면 예외 발생
- [ ] 당첨 번호에 중복이 있으면 예외 발생
- [ ] 번호가 1~45 범위를 벗어나면 예외 발생
- [ ] 보너스 번호가 당첨 번호와 중복되면 예외 발생

---

### 3. 로또 생성 (자동)
- [ ] 번호 생성 전략 인터페이스 `NumberGenerator` 정의
- [ ] 실제 구현체 `RandomNumberGenerator`:
    - [ ] 1~45 범위에서 중복 없이 6개 번호 생성
    - [ ] 번호는 오름차순 정렬
- [ ] `LottoMachine`을 통해 자동으로 N장 발행
- [ ] `Lotto` 생성 시 번호 개수(6개) 검증 수행

---

### 4. 당첨 판정
- [ ] `WinningLotto` 클래스에서 당첨 번호(6개)와 보너스 번호 관리
- [ ] `Lotto` 한 장에 대해 일치 개수 및 보너스 일치 여부 계산
- [ ] `Rank`를 통해 등수 판정:
    - [ ] 6개 일치 → 1등 (2,000,000,000원)
    - [ ] 5개 + 보너스 → 2등 (30,000,000원)
    - [ ] 5개 일치 → 3등 (1,500,000원)
    - [ ] 4개 일치 → 4등 (50,000원)
    - [ ] 3개 일치 → 5등 (5,000원)
    - [ ] 나머지 → 꽝

---

### 5. 결과 집계 및 수익률
- [ ] 모든 로또 티켓의 `Rank`를 집계하여 등수별 개수 구하기
- [ ] 총 상금 합계 계산
- [ ] 수익률(%) = `(총 상금 / 구입 금액) * 100` 계산

---

### 6. 예외 처리
- [ ] 예외 발생 시 `[ERROR] 메시지` 형식으로 출력
- [ ] 프로그램은 예외 메시지를 출력 후 종료
- [ ] 모든 예외 메시지는 요구사항 문구와 정확히 일치해야 함
